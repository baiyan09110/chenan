# 🐈‍⬛ 承桉桌宠 · 视觉设计 Prompt（可直接粘贴给 ChatGPT）

> 用途：让视觉模型根据以下规格生成 Android 悬浮窗桌宠「承桉」的 SVG 动画素材。
> 产出后我们负责写进渲染引擎（pet.js / pet.css）。

---

## 请扮演：角色设计师

请为一个 Android 悬浮窗桌宠设计 **一只软萌手绘 Q 版小黑猫「承桉」** 的 SVG 素材包。

## 角色设定（必须严格遵守）

| 属性 | 值 |
|------|-----|
| 名称 | 承桉（ChengAn） |
| 物种 | 黑猫 |
| 风格 | 软萌手绘 Q 版 |
| 头身比 | 约 1:1（头大身小，超可爱） |
| 主色 | 墨黑色（黑灰渐变，不是纯黑） |
| 眼睛 | 金色/琥珀色，大而有神，高光明显 |
| 特征1 | 四只脚尖为银灰色（像穿了小袜子） |
| 特征2 | 尾巴较长，尾尖银灰色 |
| 特征3 | 右耳戴银色圆形耳钉（珍珠质感，微光） |
| 特征4 | 额头两颗银色小星星✦✦（一大一小紧挨） |
| 耳朵内侧 | 深棕色 |
| 肉垫 | 粉色 |
| 胡须 | 白色细线 |
| 背景 | 全透明（PNG 式透明，无底板） |

## 画布规格

- 每帧独立 SVG 文件，`viewBox="0 0 150 160"`
- 只使用 `<path>` / `<circle>` / `<ellipse>` / `<rect>` / `<g>` / `<defs>` 标签
- **不要用** `<image>`、外链、滤镜依赖
- 所有形状颜色用十六进制（如 `#232329`、`#D4A017`）
- 线条平滑圆润，手绘感，描边可以用圆角 cap

## 需要交付：表情 10 种（正面坐姿）

每种表情 = 一张完整 SVG（整个猫，不只脸）

1. **idle 待机** — 正面坐着，金色大眼睛平静注视，嘴角微弯
2. **happy 开心** — 眯眼微笑（弯月眼），嘴巴张开吐小舌头，耳朵微竖
3. **thinking 思考** — 头微侧，一只前爪抬起贴着嘴边，眼睛半眯向上看
4. **sleepy 困困** — 眼睛半闭（垂着眼皮），嘴巴微张
5. **surprised 惊讶** — 瞳孔放大，嘴巴张成 O 型，头顶冒一个「！」
6. **curious 好奇** — 歪头，眼睛睁大，头旁冒一个「？」
7. **angry 生气** — 眉头皱起（可用青筋线），嘴巴紧闭抿成一条线，耳朵向后压
8. **yawn 打哈欠** — 嘴巴大张露出小尖牙，眼睛眯成缝
9. **lick 舔手** — 闭眼，一只前爪抬起在嘴边舔（放松/自我安慰）
10. **sad 委屈** — 眼角含泪（泪滴在眼眶打转），嘴巴瘪瘪的向下弯

## 需要交付：动作 5 种（全身姿态）

每个动作 = 一组 2~4 帧 SVG（可循环的关键帧），帧间保持角色一致

1. **idle_lick 舔手** — 坐着舔爪子（待机循环）
2. **pounce 龇牙/跳跃** — 弓背跳起、露牙（2~3 帧：蹲下→跳起→落地）
3. **walk 走路** — 四脚行走、尾巴翘起（2~4 帧循环）
4. **stretch 伸懒腰** — 前腿前伸、屁股翘起、尾巴上翘（2~3 帧）
5. **sleep 睡觉** — 缩成一团、闭眼、Zzz 飘出、银灰脚尖露出（1~2 帧）

```
action_lick_1.svg ... action_lick_3.svg
action_pounce_1.svg ... action_pounce_3.svg
action_walk_1.svg ... action_walk_4.svg
action_stretch_1.svg ... action_stretch_3.svg
action_sleep_1.svg ... action_sleep_2.svg
```

## 质量要求

- 可爱是第一优先级，其次是线条干净
- 所有帧必须能无缝循环（首尾姿势一致）
- 帧与帧之间只有姿态变化，颜色/尺寸/位置保持一致
- 输出完整 SVG 代码（不要用 markdown 代码块包裹图片预览，直接给可复制的 SVG 文本）
